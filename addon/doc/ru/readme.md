# Проверка цветового контраста для NVDA

Специалистам по цифровой доступности регулярно нужно убеждаться, что соотношения цветового контраста попадают в пороги, определённые Руководством по обеспечению доступности веб-контента (WCAG). Однако исторически незрячим специалистам было сложно делать это, не полагаясь на зрячих коллег или автоматизированные решения. Большинство представленных на рынке автоматизированных решений, включая WAVE и axe DevTools, лишь помечают проблемы контраста как «предложения», что-то упускают и не проверяют индикатор фокуса.

Это дополнение позволяет проверить контраст элемента в фокусе с помощью NVDA+F, элемента под курсором просмотра с помощью NVDA+Shift+F, индикатора фокуса с помощью NVDA+Shift+C, а также запустить аудит всей страницы по всем нарушениям контраста текста с помощью NVDA+Shift+Ctrl+F.

| Задача | Команда | Область |
| --- | --- | --- |
| Проверить контраст текста в фокусе | **NVDA+F** | Информация о форматировании элемента в фокусе, включая соотношение контраста |
| Проверить контраст текста под курсором просмотра | **NVDA+Shift+F** | Информация о форматировании в позиции курсора просмотра, включая соотношение контраста |
| Проверить контраст индикатора фокуса | **NVDA+Shift+C** | Кольцо фокуса относительно окружающего фона |
| Запустить аудит текста по всей странице | **NVDA+Shift+Ctrl+F** | Видимый текст на текущей странице, сгруппированный по порогу контраста WCAG |

## Контраст текста

Это дополнение расширяет существующие команды NVDA для получения информации о форматировании. Нажмите **NVDA+F** на любом тексте, чтобы услышать информацию о форматировании, включая соотношение контраста. Пример:

- Source Sans 3 ExtraLight
- 10.5pt
- чёрный на белом
- выравнивание по левому краю
- `#000000 на #FFFFFF, контраст 21.0:1`

Нажмите дважды быстро, чтобы открыть диалог в режиме обзора. **NVDA+Shift+F** использует позицию курсора просмотра вместо системной каретки.

WCAG AA требует 4.5:1 для обычного текста и 3:1 для крупного текста. WCAG AAA требует 7:1.

## Контраст индикатора фокуса

Нажмите **NVDA+Shift+C** на любом элементе в фокусе, чтобы услышать контраст между его кольцом фокуса и окружающим фоном:

> `Индикатор фокуса: #000000 на #FFFFFF, контраст 21.0:1`

WCAG оценивает индикаторы фокуса через связанные требования. Контраст нетекстовых элементов требует, чтобы визуальный индикатор фокуса имел контраст не менее 3:1 относительно соседних цветов, а появление фокуса в WCAG 2.2 добавляет требования к контрасту изменения и размеру индикатора. Это дополнение сообщает измеренный контраст; специалистам всё равно следует оценивать полное требование к появлению фокуса.

## Аудит контраста по всей странице

Нажмите **NVDA+Shift+Ctrl+F**, чтобы за один раз проанализировать каждый фрагмент текста на текущей странице. Результаты открываются в диалоге в режиме обзора, сгруппированные по серьёзности:

- Ниже 3:1 (крупный текст)
- Ниже 4.5:1 (обычный или мелкий текст)
- Ниже 7:1 (контраст текста AAA)

Текст, который достигает 7:1 или лучше, проходит все пороги WCAG и опускается. Если ничего не нарушает требований, NVDA сообщает об этом вместо открытия диалога.

Обратите внимание, что эта команда проверяет только текст, видимый в текущем состоянии страницы. Вам всё равно нужно раскрыть и протестировать другие состояния, такие как фокус, наведение, развёрнутое или свёрнутое содержимое, содержимое с отложенной загрузкой, а также текст, отрисованный нестандартно или представленный изображением. Контраст кольца фокуса проверяется отдельно с помощью **NVDA+Shift+C**.

## Как это работает

Это дополнение работает полностью на вашем компьютере. Оно не использует искусственный интеллект и не выполняет никаких сетевых запросов.

Для контраста текста оно считывает цвета переднего плана и фона, которые NVDA предоставляет для текущего текста. Оно преобразует каждый цвет sRGB в относительную яркость, а затем применяет [формулу контраста WCAG](https://www.w3.org/WAI/GL/wiki/Contrast_ratio).

Для индикаторов фокуса оно захватывает небольшую область экрана вокруг элемента в фокусе с помощью API захвата экрана Windows. Пиксели вокруг элемента анализируются, чтобы определить окружающий фон и наиболее контрастный цветовой переход вблизи его краёв. Затем соотношение контраста между этими цветами вычисляется по той же формуле.

## Установка

1. Установите из магазина дополнений NVDA (меню NVDA -> Сервис -> Магазин дополнений -> вкладка «Доступные дополнения» -> Проверка цветового контраста для NVDA -> Действия -> Установить). Либо скачайте последнюю версию по [этой ссылке](https://github.com/cartertemm/contrast-checker-nvda/releases/latest/).
2. Если вы не получаете дополнение из магазина дополнений, откройте файл .nvda-addon при запущенном NVDA. NVDA предложит установить его.

## Попробуйте

Откройте `tests/test_contrast.html` локально или [отрисованную тестовую страницу](https://ctemm.me/files/test_contrast.html) в браузере при запущенном NVDA.
Она охватывает различные распространённые сценарии, такие как контраст текста, кольца фокуса с известными соотношениями, отсутствующие кольца, кольца на основе box-shadow, небелые фоны и разные типы элементов.

## Сборка из исходного кода

Требуются Git, Python и SCons.

```
git clone https://github.com/cartertemm/contrast-checker-nvda/
cd contrast-checker-nvda
pip install scons
scons
```

Собранный файл `.nvda-addon` появляется в корне проекта.
